# Teh MORA — Stok Android V1

Aplikasi Android native sederhana untuk:
- VARIAN minuman
- CUP per pcs
- BARANG BELANJAAN
- Tambah stok
- Kurangi stok
- Data tersimpan permanen di HP melalui SharedPreferences

## Build
Buka folder ini di Android Studio terbaru, tunggu Gradle sync, lalu pilih:
Build > Build App Bundle(s) / APK(s) > Build APK(s).

Catatan: source project sudah disiapkan, tetapi APK binary belum dapat dikompilasi di lingkungan chat ini karena Android SDK/build tool tidak tersedia.
